# LinkBus - Plataforma de Transporte Escolar

Sistema de transporte escolar inteligente en tiempo real para familias, conductores y administración de colegios.

## Características

- **Rastreo en tiempo real**: Monitoreo de rutas, paradas y tiempos estimados de llegada.
- **Portal de Familias**: Estado del viaje del estudiante, notificaciones y contacto directo.
- **Panel de Conductores**: Check-in de alumnos, navegación y reportes de incidentes.
- **Administración Escolar**: Gestión de flota, asignación de unidades, control de cobros y métricas de puntualidad.

## Desarrollo

Requisitos: Node.js (v18+) y npm o bun.

```sh
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Ejecutar pruebas
npm run test

# Compilar para producción
npm run build
```
